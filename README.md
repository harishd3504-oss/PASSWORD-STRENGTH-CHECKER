# 🔐🔑 Password Strength Checker

A simple and interactive **web-based Password Strength Checker** built using **HTML, CSS, and JavaScript**.
This application evaluates the strength of a password in real-time and helps users create secure passwords.

---

## 🚀 Features

* 🔍 Real-time password strength checking
* 🔐 Validates:

  * Minimum length (8+ characters)
  * Uppercase letters (A–Z)
  * Lowercase letters (a–z)
  * Numbers (0–9)
  * Special characters (!@#$%^&*)
* 📊 Displays strength levels:

  * 🔴 Weak
  * 🟡 Medium
  * 🟢 Strong
* 🎯 Instant feedback while typing
* 💡 Simple and clean UI

## ⚙️ How It Works

1. User enters a password in the input field
2. JavaScript checks the password based on:

   * Length
   * Uppercase letters
   * Lowercase letters
   * Numbers
   * Special characters
3. A score is calculated based on these conditions
4. Strength is displayed as:

   * Weak (low score)
   * Medium (moderate score)
   * Strong (high score)
